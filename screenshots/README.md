# EmergencyCore 2.0 — feature screenshots

Created by **Abdullah Siddique** · [Portfolio](https://abdullah-siddique-dev.netlify.app/) · [LinkedIn](https://www.linkedin.com/in/mr-abdullah-siddique/) · [GitHub](https://github.com/abdullah90907)

Captured from the running React/Flask application using an isolated database. Incident examples are explicitly labelled demonstrations. Groq text and Open-Meteo result images show live responses. No production incidents were created or changed. Connection screenshots contain no credentials.

Map screenshots show real cached road data with simulated closures. External basemap tile requests were blocked during automated capture. Los Angeles unavailability is documented rather than hidden. The vision screenshot documents the interface; no authentic damage-photo inference or satellite model result is claimed.
